**Goal:** A 2-player P(win) network, antisymmetric in the players and invariant to the 8 colour relabellings by construction, trained from scratch by TD(λ) self-play with fresh targets, plus a capacity check and bench bots to compare it with Master.

**Architecture:** `src/dqn/win.rs` holds the inputs (4 row tokens + 9 globals regrouped from `board_features`), the burn `WinModel` (shared row encoder φ, pair pooling, pair encoder ψ, head g; logit z = g(x) − g(swap x)), a plain-Rust `ManualWinNet` for fast inference, and `WinStrategy` (implements `Bot` with probit-unit values and `WinProb`). `src/dqn/win_train.rs` holds the recorder, λ-returns, fresh targets, a hand-written Adam loop with soft-target cross-entropy, the self-play loop, a bench against Master and the capacity check. `src/main.rs` gets `win-train`, `win-fit` and bench bots `win` / `win-search`.

**Tech Stack:** Rust 2021, burn 0.20.1 (ndarray backend, autodiff, `burn::optim`), rand 0.8 `SmallRng`, rayon.

**Spec:** `docs/superpowers/specs/2026-10-15-win-net-design.md`

## Global Constraints

- 2-player only: `WinStrategy` panics with more than one opponent ("the win net is 2-player only"). Zero opponents fall back to an empty board, like the pair bot.
- Output = P(I finish ahead), a tie counting ½.
- Trained from scratch (random init), pure self-play; no warm start, no board-swap or colour augmentation.
- λ = 0.8; Adam learning rate 4e-4 for self-play; ε = max(0.2 · 0.95^iter, 0.07), on seat 0's active decisions only.
- Defaults: 160 iterations, 5,000 games per iteration, replay buffer of 3 iterations, 2 epochs per iteration, 400 bench games per iteration, W = 32.
- Capacity check: 300,000 training / 50,000 held-out positions, W = 16, 32, 64, Adam 1e-3, pick the smallest W with held-out MAE ≤ 0.02.
- Not touched: `pair_model/`, `champion.txt`, `dqn_model/`, the web crate's behaviour.
- Model dir `win_model/` (`config.json`, `model.mpk`, `iter-N.mpk`, `training.csv`). Do not commit trained weights from this plan.
- Formatting: `rustfmt --edition 2021 <files>` on touched files only; never `cargo fmt` on the crate.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- Extreme logits (|z| ≥ 20, late lopsided positions): `evaluate` must stay finite and strictly monotone; a saturated f32 sigmoid would collapse distinct moves to one value. Pinned in Task 3 (`probit_of_logit_is_finite_and_monotone_at_extremes`).
- Solo (no opponents): falls back to an empty opponent board instead of panicking or indexing out of bounds. Pinned in Task 3 (`no_opponent_falls_back_to_empty_board`).
- Recorder perspective: each seat's snapshots must pair that seat's post-move state with its opponent, and the two outcomes must sum to 1 (ties ½). Pinned in Task 4 (`self_play_game_records_both_seats_with_complementary_outcomes`).
- Saved weights are half precision (`CompactRecorder`): a model loaded from disk must still match the in-memory model closely, or benches measure a different net than training logged. Pinned in Task 5 (`tiny_training_run_writes_and_reloads_a_model`).
- The search's value units: `WinStrategy::evaluate` must equal Φ⁻¹(`win_prob_multi`) so the 0.15 gate and the Φ blend in `src/strategy/search.rs` mean what they mean for the pair bot. Pinned in Task 3 (`evaluate_is_the_probit_of_win_prob`).

```rust
/// Row-token width: a row's 4 features for me, then the same 4 for the opponent.
pub const TOKEN: usize = 8;
/// Global inputs: 4 per player (strikes, blanks, aggregate weight, lockable
/// rows), then the current difference / 100.
pub const GLOBALS: usize = 9;
/// Full input: 4 row tokens (red, yellow, green, blue) + globals.
pub const WIN_INPUTS: usize = 4 * TOKEN + GLOBALS;

/// Input for "me" against "opp": today's two 20-feature board blocks
/// regrouped by row. The row features are direction-free, so every colour
/// relabelling only permutes the 4 tokens.
pub fn win_input(me: &State, opp: &State) -> [f32; WIN_INPUTS] {
    let (a, b) = (board_features(me), board_features(opp));
    let mut x = [0.0f32; WIN_INPUTS];
    for r in 0..4 {
        for k in 0..4 {
            x[TOKEN * r + k] = a[4 * k + r];
            x[TOKEN * r + 4 + k] = b[4 * k + r];
        }
    }
    x[32..36].copy_from_slice(&a[16..20]);
    x[36..40].copy_from_slice(&b[16..20]);
    let cdiff = (me.count_points() - opp.count_points()) as f32;
    x[40] = (cdiff / 100.0).clamp(-1.0, 1.0);
    x
}

/// The same position from the opponent's side: swap the halves of every
/// token and of the globals, negate the difference.
pub fn swap_input(x: &[f32; WIN_INPUTS]) -> [f32; WIN_INPUTS] {
    let mut s = *x;
    for r in 0..4 {
        for k in 0..4 {
            s[TOKEN * r + k] = x[TOKEN * r + 4 + k];
            s[TOKEN * r + 4 + k] = x[TOKEN * r + k];
        }
    }
    for k in 0..4 {
        s[32 + k] = x[36 + k];
        s[36 + k] = x[32 + k];
    }
    s[40] = -x[40];
    s
}
```

```rust
// ---- Model ----

/// g(me, opp): shared row encoder φ (8 → W → W), sums within the colour
/// pairs (red + yellow, green + blue), shared pair encoder ψ (W → W) summed
/// over both pairs, then a head over [pooled rows | 9 globals]
/// (W + 9 → 2W → W → 1). ReLU throughout, linear output.
#[derive(Module, Debug)]
pub struct WinModel<B: Backend> {
    pub row1: Linear<B>,
    pub row2: Linear<B>,
    pub pair: Linear<B>,
    pub head1: Linear<B>,
    pub head2: Linear<B>,
    pub out: Linear<B>,
    activation: Relu,
}

#[derive(Config, Debug)]
pub struct WinModelConfig {
    /// Encoder width W (the head is 2W → W).
    #[config(default = 32)]
    pub width: usize,
}

impl WinModelConfig {
    pub fn init<B: Backend>(&self, device: &B::Device) -> WinModel<B> {
        let w = self.width;
        let lin = |d_in: usize, d_out: usize| LinearConfig::new(d_in, d_out).with_bias(true).init(device);
        WinModel {
            row1: lin(TOKEN, w),
            row2: lin(w, w),
            pair: lin(w, w),
            head1: lin(w + GLOBALS, 2 * w),
            head2: lin(2 * w, w),
            out: lin(w, 1),
            activation: Relu::new(),
        }
    }
}

impl<B: Backend> WinModel<B> {
    /// g per input row: `[n, WIN_INPUTS]` → `[n, 1]`.
    pub fn g(&self, x: Tensor<B, 2>) -> Tensor<B, 2> {
        let n = x.dims()[0];
        let tokens = x.clone().narrow(1, 0, 4 * TOKEN).reshape([n, 4, TOKEN]);
        let e = self
            .activation
            .forward(self.row2.forward(self.activation.forward(self.row1.forward(tokens))));
        let w = e.dims()[2];
        let asc = e.clone().narrow(1, 0, 2).sum_dim(1);
        let desc = e.narrow(1, 2, 2).sum_dim(1);
        let rows = self.activation.forward(self.pair.forward(asc)) + self.activation.forward(self.pair.forward(desc));
        let h = Tensor::cat(vec![rows.reshape([n, w]), x.narrow(1, 4 * TOKEN, GLOBALS)], 1);
        let h = self.activation.forward(self.head1.forward(h));
        let h = self.activation.forward(self.head2.forward(h));
        self.out.forward(h)
    }

    /// Antisymmetric logit z = g(x) − g(swapped), `[n, 1]`; both
    /// orientations run as one batch.
    pub fn forward(&self, x: Tensor<B, 2>, swapped: Tensor<B, 2>) -> Tensor<B, 2> {
        let n = x.dims()[0];
        let both = self.g(Tensor::cat(vec![x, swapped], 0));
        both.clone().narrow(0, 0, n) - both.narrow(0, n, n)
    }
}

/// Rows of inputs as a `[n, WIN_INPUTS]` tensor.
pub fn input_tensor<B: Backend>(rows: &[[f32; WIN_INPUTS]], device: &B::Device) -> Tensor<B, 2> {
    let flat: Vec<f32> = rows.iter().flatten().copied().collect();
    Tensor::<B, 1>::from_floats(flat.as_slice(), device).reshape([rows.len(), WIN_INPUTS])
}

/// Logits through the burn model (training-side reference; bots use
/// [`ManualWinNet`]).
pub fn model_logits(model: &WinModel<MyBackend>, rows: &[[f32; WIN_INPUTS]]) -> Vec<f32> {
    let device = Default::default();
    let swapped: Vec<_> = rows.iter().map(swap_input).collect();
    let z = model.forward(input_tensor(rows, &device), input_tensor(&swapped, &device));
    z.into_data().to_vec::<f32>().unwrap()
}
```

```rust
// ---- Manual inference path ----

/// One dense layer, weights input-major as burn stores them:
/// `w[i * d_out..][..d_out]` are input i's weights to every output.
struct Dense {
    w: Vec<f32>,
    b: Vec<f32>,
    d_out: usize,
}

impl Dense {
    fn from_linear(layer: &Linear<MyBackend>) -> Self {
        let d_out = layer.weight.shape().dims[1];
        Dense {
            w: layer.weight.val().into_data().to_vec::<f32>().unwrap(),
            b: layer.bias.as_ref().unwrap().val().into_data().to_vec::<f32>().unwrap(),
            d_out,
        }
    }

    /// `out = b + x · w`, then ReLU when `relu`. Zero inputs are skipped.
    fn apply(&self, x: &[f32], out: &mut Vec<f32>, relu: bool) {
        out.clear();
        out.extend_from_slice(&self.b);
        for (i, &xi) in x.iter().enumerate() {
            if xi != 0.0 {
                for (o, &wv) in out.iter_mut().zip(&self.w[i * self.d_out..(i + 1) * self.d_out]) {
                    *o += xi * wv;
                }
            }
        }
        if relu {
            for o in out.iter_mut() {
                *o = o.max(0.0);
            }
        }
    }
}

/// Plain-array copy of a [`WinModel`] for inference (burn's per-call
/// overhead dominates at these sizes, as for `ManualPairNet`). Numerics
/// match burn to a tolerance, not bit for bit.
pub struct ManualWinNet {
    width: usize,
    row1: Dense,
    row2: Dense,
    pair: Dense,
    head1: Dense,
    head2: Dense,
    out: Dense,
}

impl ManualWinNet {
    pub fn from_model(model: &WinModel<MyBackend>) -> Self {
        ManualWinNet {
            width: model.row1.weight.shape().dims[1],
            row1: Dense::from_linear(&model.row1),
            row2: Dense::from_linear(&model.row2),
            pair: Dense::from_linear(&model.pair),
            head1: Dense::from_linear(&model.head1),
            head2: Dense::from_linear(&model.head2),
            out: Dense::from_linear(&model.out),
        }
    }

    fn g(&self, x: &[f32; WIN_INPUTS]) -> f32 {
        let w = self.width;
        let (mut h, mut e) = (Vec::with_capacity(2 * w), Vec::with_capacity(w));
        let mut pooled = [vec![0.0f32; w], vec![0.0f32; w]];
        for r in 0..4 {
            self.row1.apply(&x[TOKEN * r..TOKEN * (r + 1)], &mut h, true);
            self.row2.apply(&h, &mut e, true);
            for (p, v) in pooled[r / 2].iter_mut().zip(&e) {
                *p += v;
            }
        }
        let mut cat = vec![0.0f32; w];
        for p in &pooled {
            self.pair.apply(p, &mut e, true);
            for (c, v) in cat.iter_mut().zip(&e) {
                *c += v;
            }
        }
        cat.extend_from_slice(&x[4 * TOKEN..]);
        self.head1.apply(&cat, &mut h, true);
        self.head2.apply(&h, &mut e, true);
        self.out.apply(&e, &mut h, false);
        h[0]
    }

    /// Antisymmetric logit z = g(x) − g(swap x).
    pub fn logit(&self, x: &[f32; WIN_INPUTS]) -> f32 {
        self.g(x) - self.g(&swap_input(x))
    }

    pub fn logits(&self, xs: &[[f32; WIN_INPUTS]]) -> Vec<f32> {
        xs.iter().map(|x| self.logit(x)).collect()
    }
}

pub fn sigmoid(z: f32) -> f32 {
    1.0 / (1.0 + (-z).exp())
}

/// Φ⁻¹(sigmoid(z)): the probit z-score of the logit's probability, the
/// value unit the search's gate and blend assume. Computed from the smaller
/// tail in f64 so it stays finite and strictly monotone for large |z|.
pub fn probit_of_logit(z: f32) -> f32 {
    let tail = 1.0 / (1.0 + (z.abs() as f64).exp()); // sigmoid(-|z|) ≤ ½
    let x = probit_lower(tail.max(f64::MIN_POSITIVE)); // ≤ 0
    (if z >= 0.0 { -x } else { x }) as f32
}

/// Φ⁻¹(p) for 0 < p ≤ ½ (Acklam's rational approximation, relative error
/// < 1.2e-9).
fn probit_lower(p: f64) -> f64 {
    const A: [f64; 6] = [
        -3.969683028665376e+01,
        2.209460984245205e+02,
        -2.759285104469687e+02,
        1.383577518672690e+02,
        -3.066479806614716e+01,
        2.506628277459239e+00,
    ];
    const B: [f64; 5] = [
        -5.447609879822406e+01,
        1.615858368580409e+02,
        -1.556989798598866e+02,
        6.680131188771972e+01,
        -1.328068155288572e+01,
    ];
    const C: [f64; 6] = [
        -7.784894002430293e-03,
        -3.223964580411365e-01,
        -2.400758277161838e+00,
        -2.549732539343734e+00,
        4.374664141464968e+00,
        2.938163982698783e+00,
    ];
    const D: [f64; 4] = [
        7.784695709041462e-03,
        3.224671290700398e-01,
        2.445134137142996e+00,
        3.754408661907416e+00,
    ];
    if p < 0.02425 {
        let q = (-2.0 * p.ln()).sqrt();
        (((((C[0] * q + C[1]) * q + C[2]) * q + C[3]) * q + C[4]) * q + C[5])
            / ((((D[0] * q + D[1]) * q + D[2]) * q + D[3]) * q + 1.0)
    } else {
        let q = p - 0.5;
        let r = q * q;
        (((((A[0] * r + A[1]) * r + A[2]) * r + A[3]) * r + A[4]) * r + A[5]) * q
            / (((((B[0] * r + B[1]) * r + B[2]) * r + B[3]) * r + B[4]) * r + 1.0)
    }
}

        let cfg = WinModelConfig::load(format!("{dir}/config.json")).expect("Failed to load win model config");
        let model = cfg

            .load_file(format!("{dir}/model"), &CompactRecorder::new(), &device)

    }

    /// unsupported, as for the pair bot).
    fn opponent(opps: &[State]) -> State {
        assert!(opps.len() <= 1, "the win net is 2-player only (got {} opponents)", opps.len());
        opps.first().copied().unwrap_or_default()
    }
}

impl Bot for WinStrategy {
    fn evaluate(&self, our_state: &State, opp_states: &[State]) -> f32 {
        self.evaluate_batch(&[*our_state], opp_states)[0]
    }

    fn evaluate_batch(&self, candidates: &[State], opp_states: &[State]) -> Vec<f32> {
        self.evaluate_batch_multi(&[(candidates, opp_states)]).pop().unwrap()
    }

    /// Probit-unit values (see [`probit_of_logit`]); move order equals the
    /// order of P(win).
    fn evaluate_batch_multi(&self, groups: &[(&[State], &[State])]) -> Vec<Vec<f32>> {
        groups
            .iter()
            .map(|(candidates, opps)| {
                let opp = Self::opponent(opps);
                candidates
                    .iter()
                    .map(|c| probit_of_logit(self.net.logit(&win_input(c, &opp))))
                    .collect()
            })
            .collect()
    }
}

impl WinProb for WinStrategy {
    fn win_prob_multi(&self, groups: &[(&State, &[State])]) -> Vec<f32> {
        groups
            .iter()
            .map(|(our, opps)| sigmoid(self.net.logit(&win_input(our, &Self::opponent(opps)))))
            .collect()
    }
}
```

```rust
    tensor::{activation::log_sigmoid, ElementConversion},

pub type Ad = Autodiff<MyBackend>;

/// TD(λ) trace decay, as for the pair net.
pub const LAMBDA: f32 = 0.8;

/// One player's game: the input after each of their decisions, and the
/// outcome from their side.
#[derive(Clone, Debug)]
pub struct Chain {
    pub inputs: Vec<[f32; WIN_INPUTS]>,
    pub outcome: f32,
}

/// 1 for a win, 0 for a loss, ½ for a tie.
pub fn outcome(me: isize, opp: isize) -> f32 {
    if me > opp {
        1.0
    } else if me < opp {
        0.0
    } else {
        0.5
    }
}

/// λ-returns over one chain: `G_last = outcome`,
/// `G_t = (1 − λ)·p_{t+1} + λ·G_{t+1}`. `ps[0]` is unused.
pub fn lambda_returns(ps: &[f32], outcome: f32, lambda: f32) -> Vec<f32> {
    let n = ps.len();
    let mut g = vec![0.0f32; n];
    if n == 0 {
        return g;
    }
    g[n - 1] = outcome;
    for t in (0..n - 1).rev() {
        g[t] = (1.0 - lambda) * ps[t + 1] + lambda * g[t + 1];
    }
    g
}

/// Rebuild every chain's targets with the current net (spec "Fresh
/// targets"): stored inputs paired with their λ-returns.
pub fn fresh_targets(net: &ManualWinNet, chains: &[&Chain]) -> Vec<([f32; WIN_INPUTS], f32)> {
    chains
        .par_iter()
        .flat_map_iter(|c| {
            let ps: Vec<f32> = net.logits(&c.inputs).into_iter().map(sigmoid).collect();
            let g = lambda_returns(&ps, c.outcome, LAMBDA);
            c.inputs.iter().copied().zip(g).collect::<Vec<_>>()
        })
        .collect()
}

/// Binary cross-entropy of sigmoid(z) against soft targets t, from logits:
/// −mean(t·log σ(z) + (1 − t)·log σ(−z)).
pub fn bce_logits<B: Backend>(z: Tensor<B, 2>, t: Tensor<B, 2>) -> Tensor<B, 1> {
    let pos = log_sigmoid(z.clone());
    let neg = log_sigmoid(z.neg());
    (t.clone() * pos + t.neg().add_scalar(1.0) * neg).mean().neg()
}

/// Train on (input, soft target) pairs: Adam, batches of 1024, a seeded
/// shuffle per epoch. Returns the model and the last epoch's mean loss.
pub fn train_epochs(
    mut model: WinModel<Ad>,
    data: &[([f32; WIN_INPUTS], f32)],
    epochs: usize,
    lr: f64,
    seed: u64,
) -> (WinModel<Ad>, f32) {
    let device = Default::default();
    let mut optim = AdamConfig::new().init();
    let mut order: Vec<usize> = (0..data.len()).collect();
    let mut last = 0.0;
    for epoch in 0..epochs {
        order.shuffle(&mut SmallRng::seed_from_u64(seed.wrapping_add(epoch as u64)));
        let (mut sum, mut batches) = (0.0f32, 0usize);
        for chunk in order.chunks(1024) {
            let xs: Vec<[f32; WIN_INPUTS]> = chunk.iter().map(|&i| data[i].0).collect();
            let swapped: Vec<_> = xs.iter().map(swap_input).collect();
            let t: Vec<f32> = chunk.iter().map(|&i| data[i].1).collect();
            let z = model.forward(input_tensor::<Ad>(&xs, &device), input_tensor::<Ad>(&swapped, &device));
            let t = Tensor::<Ad, 1>::from_floats(t.as_slice(), &device).reshape([chunk.len(), 1]);
            let loss = bce_logits(z, t);
            sum += loss.clone().into_scalar().elem::<f32>();
            batches += 1;
            let grads = GradientsParams::from_grads(loss.backward(), &model);
            model = optim.step(lr, model, grads);
        }
        last = sum / batches.max(1) as f32;
    }
    (model, last)
}

// ---- Self-play recording ----

/// Plays through the shared bot pipeline and records (my post-decision
/// state, opponent) after each decision, at the pair recorder's cadence:
/// active turns once after phase 2, passive turns after every real decision
/// (skips included). ε-greedy on active decisions, greedy on passive.
struct Recorder<B: Bot> {
    bot: B,
    epsilon: f32,
    rng: SmallRng,
    recorded: Rc<RefCell<Vec<(State, State)>>>,
}

impl<B: Bot> std::fmt::Debug for Recorder<B> {
    fn fmt(&self, f: &mut std::fmt::Formatter) -> std::fmt::Result {
        write!(f, "Recorder")
    }
}

impl<B: Bot> Recorder<B> {
    fn record(&self, post: State, opps: &[State]) {
        self.recorded.borrow_mut().push((post, opps[0]));
    }

    /// Uniform over the marks plus "no mark".
    fn random(&mut self, marks: &[Mark]) -> Option<Mark> {
        let i = self.rng.gen_range(0..=marks.len());
        marks.get(i).copied()
    }
}

fn after(state: &State, mark: Option<Mark>, otherwise: State) -> State {
    match mark {
        Some(m) => {
            let mut s = *state;
            s.apply_mark(m);
            s
        }
        None => otherwise,
    }
}

impl<B: Bot> Strategy for Recorder<B> {
    fn active_phase1(&mut self, state: &State, opp_states: &[State], dice: [u8; 6]) -> Option<Mark> {
        if self.rng.gen::<f32>() < self.epsilon {
            let marks = state.generate_white_moves(dice[0] + dice[1]);
            return if marks.is_empty() { None } else { self.random(&marks) };
        }
        active_phase1_impl(&self.bot, state, opp_states, dice)
    }

    fn active_phase2(&mut self, state: &State, opp_states: &[State], dice: [u8; 6], has_marked: bool) -> Option<Mark> {
        let marks = state.generate_color_moves(dice);
        let no_mark = if has_marked {
            *state
        } else {
            let mut s = *state;
            s.apply_strike();
            s
        };
        let mark = if marks.is_empty() {
            None
        } else if self.rng.gen::<f32>() < self.epsilon {
            self.random(&marks)
        } else {
            active_phase2_impl(&self.bot, state, opp_states, dice, has_marked)
        };
        self.record(after(state, mark, no_mark), opp_states);
        mark
    }

    fn passive_phase1(&mut self, state: &State, opp_states: &[State], dice: [u8; 6], _active: usize) -> Option<Mark> {
        if state.generate_white_moves(dice[0] + dice[1]).is_empty() {
            return None;
        }
        let mark = passive_phase1_impl(&self.bot, state, opp_states, dice);
        self.record(after(state, mark, *state), opp_states);
        mark
    }
}

/// Play one 2-player game, seat i as `bots[i]` exploring with `epsilon[i]`.
/// Returns each seat's snapshots and the final boards.
fn play_recorded<B: Bot + 'static>(
    bots: [B; 2],
    epsilon: [f32; 2],
    seed: u64,
) -> ([Vec<(State, State)>; 2], [State; 2]) {
    let bufs: [Rc<RefCell<Vec<(State, State)>>>; 2] = Default::default();
    let players: Vec<Player> = bots
        .into_iter()
        .enumerate()
        .map(|(i, bot)| {
            let recorder = Recorder {
                bot,
                epsilon: epsilon[i],
                rng: SmallRng::seed_from_u64(seed.wrapping_add(100 + i as u64)),
                recorded: bufs[i].clone(),
            };
            Player::new(Box::new(recorder), Box::new(SmallRng::seed_from_u64(seed.wrapping_add(i as u64))))
        })
        .collect();
    let mut game = Game::new(players);
    game.play();
    let finals = [game.players[0].state, game.players[1].state];
    (bufs.map(|b| b.take()), finals)
}

/// One self-play game with the current net in both seats, seat 0 exploring.
pub fn self_play_game(net: &Arc<ManualWinNet>, epsilon: f32, seed: u64) -> [Chain; 2] {
    let bot = || WinStrategy { net: net.clone() };
    let (snaps, finals) = play_recorded([bot(), bot()], [epsilon, 0.0], seed);
    let scores = finals.map(|s| s.count_points());
    [0, 1].map(|i| Chain {
        inputs: snaps[i].iter().map(|(me, opp)| win_input(me, opp)).collect(),
        outcome: outcome(scores[i], scores[1 - i]),
    })
}
```

```rust
// ---- Bench and self-play loop ----

/// Fixed paired game set (same pattern as the pair trainer's GA bench).
const BENCH_SEED: u64 = 0xB54C;

/// The win bot's share against Master (`pair_dir`) over `games` paired
/// 2-player games: seats alternate and each pair shares its dice; ties ½.
pub fn bench_vs_pair(win: &WinStrategy, pair_dir: &str, games: usize) -> f64 {
    let points: f64 = (0..games)
        .into_par_iter()
        .map_init(
            || PairStrategy::load(pair_dir),
            |pair, i| {
                let (pair_idx, rot) = ((i / 2) as u64, i % 2);
                let dice = |seat: u64| Box::new(SmallRng::seed_from_u64(BENCH_SEED.wrapping_add(pair_idx * 2 + seat)));
                let w: Box<dyn Strategy> = Box::new(win.clone());
                let p: Box<dyn Strategy> = Box::new(PairStrategy::from_shared(pair.model.clone(), pair.device.clone()));
                let players = if rot == 0 {
                    vec![Player::new(w, dice(0)), Player::new(p, dice(1))]
                } else {
                    vec![Player::new(p, dice(0)), Player::new(w, dice(1))]
                };
                let mut game = Game::new(players);
                game.play();
                let s: Vec<isize> = game.players.iter().map(|p| p.state.count_points()).collect();
                outcome(s[rot], s[1 - rot]) as f64
            },
        )
        .sum();
    points / games.max(1) as f64
}

pub struct WinTrainCfg {
    pub dir: String,
    pub iterations: usize,
    pub games: usize,
    pub epochs: usize,
    /// Bench games against Master per iteration (0 = none).
    pub bench: usize,
    pub width: usize,
    /// Iterations of games kept in the replay buffer.
    pub buffer: usize,
    /// Resume: load `dir`'s model and continue the ε schedule from here.

/// Spec "Training": per iteration, play `games` self-play games with the
/// current net, rebuild every buffered chain's targets with it, train
/// `epochs` epochs, save `model.mpk` and `iter-N.mpk`, bench against Master
/// and append to `training.csv`. Returns the final bot.
pub fn self_play_train(cfg: &WinTrainCfg) -> WinStrategy {
    let device = Default::default();
    <Ad as Backend>::seed(&device, TRAIN_SEED);
    std::fs::create_dir_all(&cfg.dir).expect("Failed to create the model dir");
    let config_path = format!("{}/config.json", cfg.dir);
    let log_path = format!("{}/training.csv", cfg.dir);
    let mut model: WinModel<Ad> = if cfg.start_iteration > 0 {
        WinModelConfig::load(&config_path)
            .expect("Failed to load win model config")
            .init::<Ad>(&device)
            .load_file(format!("{}/model", cfg.dir), &CompactRecorder::new(), &device)
            .expect("Failed to load win model to resume")
    } else {
        let mcfg = WinModelConfig::new().with_width(cfg.width);
        mcfg.save(&config_path).expect("Failed to save win model config");
        std::fs::write(&log_path, "iteration,games,loss,share_vs_master,elapsed_s\n").expect("Failed to write log");
        mcfg.init::<Ad>(&device)
    };
    let start = std::time::Instant::now();
    let mut buffer: std::collections::VecDeque<Vec<Chain>> = std::collections::VecDeque::new();

    for it in cfg.start_iteration..cfg.start_iteration + cfg.iterations {
        let epsilon = (0.2 * 0.95f32.powi(it as i32)).max(0.07);
        let net = Arc::new(ManualWinNet::from_model(&model.valid()));
        let chains: Vec<Chain> = (0..cfg.games)
            .into_par_iter()
            .flat_map_iter(|g| {
                let seed = TRAIN_SEED.wrapping_add(((it * cfg.games + g) as u64).wrapping_mul(1000));
                self_play_game(&net, epsilon, seed)
            })
            .collect();
        buffer.push_back(chains);
        while buffer.len() > cfg.buffer {
            buffer.pop_front();
        }
        let refs: Vec<&Chain> = buffer.iter().flatten().collect();
        let data = fresh_targets(&net, &refs);
        let (trained, loss) = train_epochs(model, &data, cfg.epochs, cfg.lr, TRAIN_SEED.wrapping_add(it as u64));
        model = trained;

        let inference = model.valid();
        inference
            .clone()
            .save_file(format!("{}/model", cfg.dir), &CompactRecorder::new())
            .expect("Failed to save win model");
        std::fs::copy(format!("{}/model.mpk", cfg.dir), format!("{}/iter-{}.mpk", cfg.dir, it + 1))
            .expect("Failed to save checkpoint");

        let share = if cfg.bench > 0 {
            Some(bench_vs_pair(&WinStrategy::from_model(&inference), "pair_model", cfg.bench))
        } else {
            None
        };
        let elapsed = start.elapsed().as_secs();
        let share_text = share.map(|s| format!("{:.1}%", s * 100.0)).unwrap_or_else(|| "-".into());
        println!(
            "Iteration {:>3}: ε {epsilon:.3}, {} positions, loss {loss:.4}, vs Master {share_text}, {elapsed}s",
            it + 1,
            data.len()
        );
        use std::io::Write;
        let mut f = std::fs::OpenOptions::new().append(true).create(true).open(&log_path).expect("Failed to open log");
        let share_csv = share.map(|s| format!("{s:.4}")).unwrap_or_default();
        writeln!(f, "{},{},{loss:.5},{share_csv},{elapsed}", it + 1, cfg.games).ok();
    }
    WinStrategy::from_model(&model.valid())
}
```

```rust
// ---- Capacity check ----

/// Post-move positions from Master-vs-Master games (both seats, no
/// exploration), labelled with today's net's P(win). Games are seeded from
/// `seed` in fixed blocks, so the result is deterministic.
pub fn master_positions(count: usize, seed: u64, pair_dir: &str) -> Vec<([f32; WIN_INPUTS], f32)> {
    const BLOCK: u64 = 256;
    let mut out = Vec::with_capacity(count);
    let mut block = 0u64;
    while out.len() < count {
        let chunk: Vec<Vec<([f32; WIN_INPUTS], f32)>> = (0..BLOCK)
            .into_par_iter()
            .map_init(
                || PairStrategy::load(pair_dir),
                |pair, g| {
                    let mk = || PairStrategy::from_shared(pair.model.clone(), pair.device.clone());
                    let game_seed = seed.wrapping_add((block * BLOCK + g).wrapping_mul(1000));
                    let (snaps, _) = play_recorded([mk(), mk()], [0.0, 0.0], game_seed);
                    let posts: Vec<(State, State)> = snaps.into_iter().flatten().collect();
                    let groups: Vec<(&State, &[State])> =
                        posts.iter().map(|(me, opp)| (me, std::slice::from_ref(opp))).collect();
                    let ps = pair.win_prob_multi(&groups);
                    posts.iter().zip(ps).map(|((me, opp), p)| (win_input(me, opp), p)).collect()
                },
            )
            .collect();
        out.extend(chunk.into_iter().flatten());
        block += 1;
    }
    out.truncate(count);
    out
}

/// Mean |sigmoid(logit) − target| over `data`.
pub fn mean_abs_error(net: &ManualWinNet, data: &[([f32; WIN_INPUTS], f32)]) -> f32 {
    let total: f32 = data.iter().map(|(x, p)| (sigmoid(net.logit(x)) - p).abs()).sum();
    total / data.len().max(1) as f32
}

pub struct FitCfg {
    pub train: usize,
    pub test: usize,
    pub epochs: usize,
    pub widths: Vec<usize>,
    pub lr: f64,
}

/// Held-out MAE at which a width counts as big enough (spec "Capacity check").
pub const FIT_MAE: f32 = 0.02;

/// Spec "Capacity check": fit each width to today's P(win) on Master
/// positions and report held-out MAE; the fitted nets are discarded.
pub fn capacity_check(cfg: &FitCfg) -> Vec<(usize, f32)> {
    let device = Default::default();
    println!("Generating {} training and {} held-out positions…", cfg.train, cfg.test);
    let train = master_positions(cfg.train, TRAIN_SEED, "pair_model");
    let test = master_positions(cfg.test, TRAIN_SEED ^ 0x7E57_0000_0000, "pair_model");
    let mut results = Vec::new();
    for &w in &cfg.widths {
        <Ad as Backend>::seed(&device, TRAIN_SEED);
        let model = WinModelConfig::new().with_width(w).init::<Ad>(&device);
        let (model, loss) = train_epochs(model, &train, cfg.epochs, cfg.lr, TRAIN_SEED);
        let mae = mean_abs_error(&ManualWinNet::from_model(&model.valid()), &test);
        println!("  W = {w:>3}: train loss {loss:.4}, held-out MAE {mae:.4}");
        results.push((w, mae));
    }
    match results.iter().find(|(_, mae)| *mae <= FIT_MAE) {
        Some((w, _)) => println!("Smallest width with MAE ≤ {FIT_MAE}: W = {w}"),
        None => println!("No width reached MAE ≤ {FIT_MAE}: decide before training"),
    }
    results
}
```
